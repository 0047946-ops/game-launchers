# 放置天堂啟動器 (Game Launchers)

專為《放置天堂》打造的 Android 啟動器，支援多伺服器切換、自動外掛注入，以及與網頁版互通的存檔匯出／匯入。

## 功能特色

- 多伺服器選擇（原版 / 加掛版）
- 自動注入 10 大外掛模組 + TMEngine 防斷線引擎
- 強化存檔系統（智慧檔名、與網頁版互通）
- 一鍵啟動，無需手動貼上腳本

## 下載

請至 [Releases](https://github.com/0047946-ops/game-launchers/releases) 下載最新 APK。

## 使用方式

1. 安裝 APK
2. 開啟後選擇伺服器
3. 點擊啟動即可自動載入遊戲與外掛
